## Who builds hsh?

hsh is written by [Sebastien Rousseau](https://sebastienrousseau.com/) and
the Hash (HSH) library contributors. He is on
[GitHub](https://github.com/sebastienrousseau) as sebastienrousseau. Version
0.0.9, in May 2026, rewrote the library around `Policy` and rehash on login.

## Project facts

| | |
| :--- | :--- |
| **Crates** | `hsh`, `hsh-cli`, `hsh-kms`, `hsh-digest` and `hsh-backend-awslc` on crates.io |
| **Language** | Rust, 2021 edition (2024 for `hsh-cli`) |
| **Rust version** | 1.85 or newer for the library in practice, 1.88 for `hsh-cli` |

## How is it versioned?

hsh is pre-1.0 and follows Semantic Versioning; while the version is 0.0.x,
any release may change the API. The repository's
[API stability document](https://github.com/sebastienrousseau/hsh/blob/main/doc/API-STABILITY.md)
sorts each public item into a stability tier, ahead of 1.0.
